## 老訂閱切換決策與操作指南

### 是什麼

The X Subscription 統一大訂閱在 2026 年 10 月 12 日上線。不主動切換的使用者，原有方案、價格與功能維持現狀不變。年付週期完整保留至自然到期，後續若有變動只在續訂時生效。

**操作在網頁端一旦確認完成便永久生效，聯繫客服也無法撤回或恢復老套餐**。舊訂閱結算時自動終止並按天折算退款，退款不能抵扣需全額支付的新套餐，帳單週期從當天重新計算。手機客戶端目前不支援切換，必須在網頁端進行。

| 支付渠道與訂閱產品 | 退款途徑與使用者操作 |
| :--- | :--- |
| 網頁端直接購買的舊方案 | 官方自動按比例退款到原支付卡，無需額外人工操作。 |
| Apple 渠道訂閱的 Grok / X Premium | 官方協助提交申請，由 Apple 最終決定退還金額。 |
| Apple 渠道訂閱的 Cursor | **使用者必須親自前往 iOS 系統的「Apple ID → 訂閱」手動取消，並向 Apple 客服申訴退款**。 |
| Google Play 渠道訂閱的服務 | **使用者必須在 Google Play 的「支付和訂閱」中手動取消自動續訂**。 |

### 實戰案例：社群作者面對大一統訂閱的決策實錄

社群開發者持有有效期至 2027 年的年費方案（作者自述，未核），排查用量後決定**暫時不把手裡的老訂閱切換為新版大一統訂閱**，同時關閉原方案自動續費繼續觀望。

老方案帶有長期優惠，強行切換後原優惠直接作廢。新方案每週共享池只覆蓋自家模型，所有第三方模型呼叫都需按 API 標價另行付費。新方案每週用量池為各產品共享，Bot 執行過多會擠佔網頁端與程式碼補全的正常額度。

| 人群分類 | 典型特徵與核心訴求 |
| :--- | :--- |
| 建議換的人群 | 單獨購買多個零散訂閱且每月開銷遠超 30 美元，主要用官方模型，對 Grok Bot 自動化與 X 帳號運營有強捆綁需求。 |
| 不建議換的人群 | 持有含額外第三方模型額度的舊方案，或只在 Cursor 重度寫程式碼、對 X 社交權益與影片生成無需求。 |

切換前先打開用量面板查看真實呼叫分佈，摸清自家模型與第三方模型比例。AI 工具儘量按月訂閱，套餐政策兩三個月就會重組，鎖定長週期年費容易陷入被動（作者自述，未核）。**通過 Apple 訂閱過 Cursor 的使用者，決定遷移後必須在手機後台手動取消自動續訂**，網頁端升級不會代為處理。

### 做到什麼程度算好

保留老方案的使用者，需確認自動續訂狀態符合預期，核心模型額度完好。

**決定切換新方案的使用者，需確認舊訂閱已徹底解除且原渠道收到退款，新方案按 Premium 正常計費，兩端沒有出現重複計費或通道衝突。**
