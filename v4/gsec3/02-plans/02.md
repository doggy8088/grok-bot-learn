## 每週共享用量池：額度結算與多端共用機制

### 是什麼

The X Subscription 每週給一個固定額度池，到期自動重新整理。**Grok 網頁端、Bot 與 Cursor 補全問答共用這個池子**。Mac 與 iPhone 登錄同帳號額度實時同步，換設備不重複扣額。

| 模型類別 | 結算規則 |
| :--- | :--- |
| 官方模型 | 計入共享池，網頁端與 Bot 都在此扣額，消耗快慢只看任務量與步數。 |
| 第三方模型 | **不計入共享池**，在 Cursor 中按 API 標價單獨扣費。 |

系統自動指派 Bot 底層模型，統一標為“Grok Bot 用量”，無法自選或遮罩。詳情見 [Grok Bot 模型](https://cursor.com/cn/help/grok-bot/models.md)。

### 怎麼做

想避免前三天耗光額度，日常分三步規劃。

1. **周初先跑核心重任務**。優先處理核心程式碼編寫、架構搭建與複雜邏輯除錯。
2. **避開高消耗操作**。批量做影片、高頻輪詢與多 Bot 聯動消耗最快（作者自述，未核）；影片建議去網頁端做，別放進 Bot 工作流。
3. 關注重置週期。記清面板上的每週重置日，臨近重置還有富餘時，再集中做資料整理或深度審查。

### 做到什麼程度算好

**常規自動化把日均消耗穩在 10% 到 15%**。每週重置前一天留約 20% 緩衝，且沒收到額度告急彈窗，節奏就算剛好。
