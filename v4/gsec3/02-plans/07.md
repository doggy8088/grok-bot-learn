## 容易踩的坑

### 選購與訂閱

- **用 Bot 別買 8 美元的 Plus 檔**。它不含 Grok Bot 和 Cloud agents，想用 Bot 必須選 30 美元的 Premium 檔。
- **Cursor Pro 和 SuperGrok 額度不疊加**。兩邊同時開不會給雙倍額度，系統只按一方算，純屬浪費錢。
- 第三方模型單獨按 API 標價計費。The X Subscription 周共享池只包自家模型。
- **選月付，別買年費**。工具和規則變動頻繁，年費會鎖死後續調整的自由度。

### 綁定與退訂

- **帳號關聯終身不可逆**。Cursor 綁定 SuperGrok 或 X Premium+ 以後客服無法解綁，千萬別拿測試小號授權。
- 老訂閱遷移只能在電腦網頁端操作，手機 App 沒開放切換入口。
- **必須去 iPhone 手動取消 Cursor 續費**。網頁端換了統一訂閱不會自動停掉 App Store 扣費，不手動退訂會被兩邊重複扣。

### 額度與使用

- **開啟按需用量並設月度限額**。每週共享池耗盡且沒開按需時，Bot 會立刻停止回應。
- **多 Bot 協作走點對點通信**。群聊每條訊息都會向所有 Bot 廣播計算，拉進常駐群聊幾輪就會耗盡周額度。
