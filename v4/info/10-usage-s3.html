省額度四步工作流

01

鎖定計費與
安全底線

Settings > Usage & Billing
核對套餐、用量與倒計時；
卡住點 Stop 強制結束。

除錯時關 Additional Usage / On-demand

send、post、buy、transfer、delete、permissions
設為 Ask first 人工批准

02

規範會話與
交互

單任務單會話，做完立即歸檔。

記錄長文存進 /workspace/，
只回結論和路徑，嚴禁貼回。

X 搜尋限每分 30 次、
每天 1000 次（不扣周額度）

提取核心事實，以 3 到 5 條要點輸出

會話臃腫時用 Duplicate 重置

03

能力路由與
分流

主 Bot 只負責拆解、派發與彙總，不寫長程式碼或轉大文件。

寫程式碼走 Cursor 雲端 Agent
（走 Cursor 額度不扣周額度）

或在虛擬機器無頭跑 Grok Build CLI / Codex CLI。

截圖與音影片由雲端電腦命令列處理，或用免費模型轉文字再餵給 Bot。

04

定時任務
改造

Details > Routines 裡，
暫停或刪除過去一周天天報「沒有變化」的例程

換 Linux 指令碼低成本輪詢，
有變動再發 Webhook 喚醒 Bot。

保留例程寫入靜默指令

「檢查後若無變化，直接結束任務，嚴禁輸出任何文字」。
