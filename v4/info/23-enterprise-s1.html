日常組態：儀表盤的四步

1

劃分權限與基礎開關

  • Manage Group Access 勾選試點
  • 本地執行設為 Never allow
  • Auto-add 選 All team 或指定群組
2

組態審批鎖與規則

  • 開啟 Enforce Auto-review 模式
  • 高危操作設為 Ask first
  • 衝突時強制以 Ask first 為準
3

設定網路與密鑰

  • 網路選團隊允許列表或加預設值
  • 可關閉預設開啟的 sudo
  • Team Secrets 最多 100 條
4

組態群組級策略

  • 只能放寬、不能更嚴
  • 網路按最嚴執行
  • 權限按最寬生效

兩版權限

團隊版
  • 全員預設開啟
  • 共享靜態出口 IP
  • 基礎審計與團隊規則
企業版
  • 按組授權與 SCIM 2.0
  • sudo 和網路白名單
  • 操作錄製與 OpenTelemetry 匯出

做到什麼程度算好

  • 明確區分試點群組與未授權群組
  • 團隊規則與 Auto-review 規則已鎖定
  • 高危操作百分之百觸發審批攔截
