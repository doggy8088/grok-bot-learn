接入外部工具：先跑通介面，再掛連線器

在把外部工具引進行動流之前，先明確接入的技術層級。

1

瀏覽器與雲端電腦介面

人在軟體裡能手動點完的日常交易

先這樣做

通過持久化雲端電腦和內建瀏覽器模擬操作。驗證流程的穩定性和業務價值。

→
2

官方連線器與外掛

業務路徑跑通且需要更高穩定性

再這樣做

接入官方 Connect Apps 中的外掛。僅啟用當前工作流直接相關的外掛，完成單項任務除錯。

→
3

外部 API 與專用指令碼

需要承載高頻、大吞吐量的自動化流程

最後考慮

呼叫底層 API，或通過 CLI 指令碼執行。

接入原則 連線器更穩定，但絕不能未經驗證就盲目堆砌。不要僅僅因為平台提供了某個連線器就順手掛上。
