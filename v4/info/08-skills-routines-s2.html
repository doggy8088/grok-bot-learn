例程：設定、查看與測試

1

設定例程

在聊天框發指令直接建立。

手機端點選 Add routine，補齊指令發送即可建立。

時區檢查路徑：
Settings → Bot → Timezone。

2

查看與管理

桌面端進入 Details，在例程列表能看執行時期間或 Paused。

點選具體例程可查：Instruction、When to run 與 Webhook。

開關可隨時 Pause 或 Resume；手機端狀態與桌面端雙向實時同步。

3

測試例程

在桌面端詳情頁點選底部的 Test 按鈕即可手動觸發。

按鈕狀態變為 Running…，執行回饋直接打在聊天視窗中。

測試執行的是真實操作。

涉及刪改先用沙箱資料測試。

規格與限制

50 個每個 Bot 最多建立
20 次系統保留最近執行記錄
5 分鐘定時例程最短觸發間隔
不可逆刪除例程，後續執行會永久終止

計劃排程

Auto-detect

自動跟隨當前電腦時區

手動指定時區

手動下拉選擇對應時區

新建定時例程不會立刻首跑，必須等待下一個計劃時間點。週末若需連續巡檢，指令中必須明確強調“包括週末在內每天執行”。
