私有網路接入

Grok Bot 跑在雲端，訪問內網必須打通私網。

兩種接入方式

桌面端路由

適合臨時除錯。流量走本機網卡，管理員可在後台一鍵禁用。

Team Setup 安裝客戶端

常態化訪問且僅限企業版。由 IT 統一維護指令碼。

網路控制

僅團隊允許列表時，必須把網路工具的控制面加入允許列表。

常態化訪問：由指令碼接入內網

方案一

接入 Tailscale 組網

新增 Tailscale 認證密鑰 TS_AUTHKEY，綁定專屬 ACL 標記，嚴格限制存取權限。

方案二

接入 Cloudflare Tunnel

私有 HTTP 服務由 Cloudflare Access 鑑權；私有 TCP 服務打開本地轉發端口。

Team Setup 指令碼如何執行

Bot Computers
開機時執行

以 sudo 普通使用者身份在 Debian Linux 虛擬機器中跑。

每天約週期重新整理一次

超時上限 30 分鐘。

check 驗證

退出碼為 0 就跳過安裝；執行失敗不阻塞電腦啟動，會在下次週期重新整理時重試。

做到什麼程度算好

✓

新建或重建的 Bot 電腦啟動完成後，自動出現在管理主控台設備列表中，狀態為線上。

✓

check 指令碼能在後續每日輪巡重新整理中穩定返回 0，不會重複執行安裝邏輯。

✓

敏感 Token 完全由 Team Secrets 注入，清單文本和執行記錄中沒有任何明文憑據。
