移交螢幕，不交密碼

登錄授權是一個高頻場景

不要把網站帳號、密碼或 API Token 發進聊天框

這種做法有極大的安全隱患，會把憑據暴露給模型的推理上下文與外部傳輸鏈路。

Bot 與你使用同一個瀏覽器環境處理服務登錄的鐵律是「移交螢幕，不交密碼」。

瀏覽器接管標準步驟

1

觸發暫停

打開目標登錄頁；遇到輸入密碼、掃碼或雙重驗證（2FA）時主動暫停，交出控制權。

2

接管輸入

在客戶端點選全螢幕或通過實時畫面接管滑鼠與鍵盤。

3

人工登錄

由你本人在雲端瀏覽器內直接敲入帳號密碼，或者使用手機掃描螢幕上的二維碼完成二次驗證。

4

移交執行

登錄成功並進入操作頁面後，通知 Bot 恢復執行。

↓
恢復執行Bot 會直接複用瀏覽器當前已有的會話 Cookie，自始至終接觸不到你的明文密碼。
