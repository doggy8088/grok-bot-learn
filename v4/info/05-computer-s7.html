登記總帳

REGISTRY.md + registry.json

單服務恢復指令碼

restore/restore-<服務名>.sh

總執行入口

restore/restore-all.sh

原始碼歸檔

service-src/：過濾 .env、記錄、歷史流水與本地虛擬環境

密鑰永遠不進倉庫：只記錄絕對路徑

重置後，按總帳恢復到可用狀態

01先讀總帳列出登記項、必恢復項、只留密鑰項
→
02放回原始碼只補缺失的，已有目錄不覆蓋
→
03按依賴恢復系統依賴 → 命令列工具 → 常駐服務與定時任務
→
04逐項健康檢查失敗先修一次；修不好記下原因，繼續下一項
→
05交驗收清單成功 / 失敗 / 等我處理

每次新服務入帳

工具名稱、短 ID、負責的 Bot
原始碼、組態與持久資料路徑
安裝方式與系統依賴
啟動命令與健康檢查命令
是否屬於“必恢復”項
人工干預：掃碼、OAuth 或設備綁定

冪等與邊界

恢復指令碼必須冪等：重複執行也不會組態衝突或行程重複拉起。
需要真人完成的事：重新提供的密鑰、OAuth、掃碼、設備碼；每做完一項馬上覆查。
故意暫停的任務保持暫停：照總帳寫明的原因和重開條件執行。
