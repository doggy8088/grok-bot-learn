## 21.4 百萬撤離方案：跨帳號與跨平台遷移實戰

[《Grok Bot 百萬撤離：一套完善的 Agent 系統備份方案》](https://jcng5q8n0f3z.feishu.cn/wiki/W0TCwnTmbiIJ9KkF4S4cV6ifnCh)

### 遷至新 Grok 帳號

1. 新帳號新增記憶管家樣板。
2. 在 `/workspace` 組態 Git 憑據並拉取備份倉庫。
3. 喚醒記憶管家，解析根目錄 `RESTORE.md`。
4. 管家按 `bots/agent-spec.md` 讀名稱、頭像描述與 Description 填入組態，把 `MEMORY.md` 注入初始上下文。
5. 執行 `vm-services/restore/restore-all.sh` 恢復虛擬機器系統依賴與服務。

**基礎設定與記憶還原度約 80%（作者自述，未核）。** 本地非結構化文件、編譯快取和對話歷史無法恢復，依賴 Cookie 或 OAuth 的登錄態必須人工重新掃碼組態。

### 遷至本地開源系統

- **Hermes 體系**：把各 Bot 的 `MEMORY.md` 放入記憶工作區，`agent-spec.md` 裡的 Description 貼入 System Prompt。
- **OpenClaw 體系**：**把備份庫中的 `bots/` 目錄直接掛載到 OpenClaw 知識目錄下。**
