## 認識共享底座與建立第一個 Bot

### 共享底座的核心特性

每位付費使用者獨享一台 Linux 虛擬機器（早期測試約為 8 核 16GB 記憶體，以官方實際分配為準），配有終端、瀏覽器與持久化磁盤。

- **所有 Bot 共享同一台機器與登錄態**：共用 `/workspace` 目錄，分設 Bot 只是切分崗位上下文，無法作為安全隔離。
- **跨 Bot 協作必須依賴文件落盤**：Bot 間看不到彼此聊天記錄，Bot A 須將產物寫入 `/workspace` 具體文件，Bot B 讀文件接力工作。
- 遇到密碼、人機驗證碼或支付認證時，展開右側實時畫面可隨時接管控制，不用在輸入框輸入敏感憑證。

### 建立與設定 Bot

首次登錄系統會自動生成預設的 Grok Bot。

1. 新建：點側欄 + 按鈕（快速鍵 Cmd+N）選 Create new Bot，或在輸入框輸名字後點選建立對應 Bot。
2. 重命名與標記：右鍵側欄 Bot 選“重命名機器人”，或在聊天頂部直接改；下方可填職務標記（Label，手機端為 Title (optional)）。
3. 換頭像：點頂部詳情頭像，可挑內建圖形、輸入提示詞生成（Generate），或上傳 25 MB 以內的本地圖片（Upload）。
4. 設職責：**個人 Bot 已取消獨立的設定頁與 Description 框**，規則直接發在首條訊息並要求它記住，會自動存入專屬記憶區；團隊 Bot 仍可在“關於”欄編輯描述。
