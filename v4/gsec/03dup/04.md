## 常見登錄問題排查

**認證報錯或循環跳轉別急著重裝**，多為快取或攔截問題。

排查先走這四步。
1. 客戶端更新到最新版本，退號重登。
2. 清除瀏覽器中 `cursor.com` 和 `x.ai` 的 Cookie，或用無痕窗口重試。
3. 瀏覽器登錄 `x.ai/bot`，確認帳號在網頁端能建立會話。
4. 剛切訂閱或開權限報錯的，**靜置等待 30 至 60 分鐘**讓會話重新整理。

**簡訊連錯會被風控鎖定**，本地無法恢復。若仍循環報錯、提示 GitHub 404 或被攔截，向支援團隊提交工單，附上註冊郵箱與報錯文本，並提供版本資訊、已試步驟和介面截圖。

具體細則查閱 [登錄 Grok Bot](https://cursor.com/cn/help/grok-bot/sign-in)。
