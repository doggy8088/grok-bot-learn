## 用量影響與額度控制：The X Subscription 下的多 Bot 治理

2026-10-12 起 Grok Bot 納入 The X Subscription，**統一按周共享額度**。

| 檔位 | 價格 |
| :--- | :--- |
| Premium | $30/月 |
| Super | $100/月 |
| Ultra | $200/月 |

### 規則與防燒策略

1. **回覆與握手訊息都計費**。私聊團隊 Bot 扣自己額度，群聊扣發起方的，周初耗盡整週停擺。
2. 群聊 Bot 壓在 3 個以內，**堅決用 1+N 串行替代自由群聊**。
3. 清洗等輕任務用基礎模型，核心推導才用頂級推理模型。
4. 沒跑穩前**別設半小時或每小時的定時例程**，防夜間重試上百次耗盡額度。

### 驗收標準

- **周額度平穩消耗**，沒有夜間死循環。
- 模型分層分明，費用分攤到具體提問者。
