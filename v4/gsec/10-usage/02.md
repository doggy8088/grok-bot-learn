## 高耗操作清單：堅決避開的六大陷阱

參考出處：[《4.1 額度與成本：省額度清單》](https://jcng5q8n0f3z.feishu.cn/wiki/KFbzwPhAliezlBkkvIuc1Abgn4h)、[《Grok Bot 額度超長續航保姆級新手指南（直接發給 Bot！）》](https://jcng5q8n0f3z.feishu.cn/wiki/OPMJw2EgtiWMiJkcrzFc6gJ8nlf)。

| 高耗操作 | 費額度原因 | 避坑做法 |
| :--- | :--- | :--- |
| 多 Bot 群聊 | 互相喚醒導致 token 翻倍空轉 | 單主導 Bot 配 Subagents 派活，或人工單聊 |
| 對話直接喂圖與影片 | 歷史幀常駐，每輪全量重讀買單 | 終端命令列處理，Bot 只接百字內結構化文本 |
| 全天高頻輪詢 | 15 分鐘一次每週 672 次，多在確認無變動 | 收緊到工作時間，或改用系統指令碼加 Webhook |
| 一條會話用到底 | 數十輪後單輪重讀數十萬 token | 單任務單會話，定期總結並 Duplicate 重置 |
| 無保護重試死循環 | 報錯後連續自我嘗試數十次 | **提示詞強制設 2 次重試上限**，失敗立刻阻斷問人工 |
| 盲目開按量付費 | 死循環可能一夜產生高額帳單 | **平時關閉按需付費**，開啟必須設嚴格低額月度上限 |
