**不用公網 IP 和自備伺服器**，靠飛書長連線與官方 Python SDK 掃碼免配後台，把 3 個 Bot 接進飛書。每個 Bot 設獨立門鈴觸發器，由應用管家維護帳本。

- **嚴格限制僅在艾特自身或全員時轉發**，避免群內閒聊引發模型空轉。
- **關鍵確認節點直接推送交互卡片**，點選按鈕即可放行，省去兩端介面來回切換的麻煩。
