## 案例一：Webhook 與快捷指令建構知識自動入庫流水線

**方案把抓取、音影片轉錄與總結全放在 Grok Bot 雲端，手機只發 URL 觸發。** 鐵柱AGI（@cgnot996）借[例程](https://cursor.com/cn/help/grok-bot/routines)的 Webhook 實作了發請求即刻啟動。

### 搭建步驟
1. 桌面端 Details 找到 Routines。讓 Bot 建立解析任務，**妥善保存生成的 Webhook URL 與 key**。
2. 新建快捷指令“發送給知識庫 Bot”，新增“獲取 URL 內容”並按表組態參數。

| 參數 | 設定值 |
|---|---|
| URL | Webhook 地址 |
| 方法 | POST |
| 頭部 | 鍵名 `Authorization`，值 `Bearer <key>` |
| 請求體 | 選 JSON，添入“快捷指令輸入” |

3. **針對封閉應用加裝輔助輸入框**。微信常禁用分享面板，需建第二條指令（“從選單中選取”加“請求文本”）中轉，綁定到 iPhone 操作按鈕，按鍵即可粘貼發送。
