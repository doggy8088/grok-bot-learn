## 適合與不適合的任務型別

**給 Grok Bot 派活，先看三條過濾標準。**
1. 網頁端、終端或 API 能跑通。
2. 中間文件或最終報告由人工直接核驗。
3. 高危動作能停下來等人工彈窗批准。

**它適合流程固定、高頻重複且跨工具呼叫的活。**
- **情報巡檢**：定期盯固定官網、Changelog 或社媒出摘要表。
- **線索清洗**：CRM 撈目標帳戶，結合公開資訊起草外聯信供審核。
- **財務對帳**：每週核對發票，標記缺票並催收。
- **缺陷復現**：讀 Issue 在預發表環境模擬復現，提記錄與截圖。
- **經營晨報**：每天彙總庫存、訂單與流量指標，揪出例外點。

**別硬塞不匹配的活，容易白耗每週額度甚至失控。**
- **即時問答**：查報錯、翻短文用普通網頁模型幾秒搞定，不用雲端電腦。
- **本地寫碼**：中斷點除錯與 Git 衝突放本地 Codex CLI 或 Claude Code；一澤提醒其上下文有限，適合調研驗收，別用來純寫程式。
- **生活瑣事**：管日曆、買日用品缺乏企業級資料源，硬搬很彆扭。
- **無增量輪詢**：每 5 分鐘無條件重新整理會空耗推理額度。
- **高危操作**：群發郵件、對外發文，或者扣款刪庫，必須留人工閘門。
