## 典型實戰案例拆解

### 金塵馬的情報調研崗

金塵馬（@jinchenma_ai）搭前沿動態追蹤 Bot。
1. 在 Description 寫明規則，定為情報調研員。
2. 派單按結果與來源、限制、格式及確認點五要素檢索 X 平台長文，區分影片帖並標曝光量，**無一手資料嚴禁編造**。
3. 調通格式後，指令 Bot **沉澱為 Skill**「AI 課程情報蒐集」。
4. 測通後設 Routine，工作日 8:10 自動彙報。
5. 建「內容總監」審選題，初稿存至 `/workspace/grokbot-demo/`。

**規則沉澱進崗位說明，臨時需求走訊息**，多 Bot 靠 `/workspace` 存盤解耦。實操見[《萬字長文｜Grok Bot 從入門到精通｜金塵馬》](https://jcng5q8n0f3z.feishu.cn/wiki/MIKpwiUXpiE9mWkyG8ccFM6Znee)。

### 金塵馬的電商運營團隊

團隊升級為 4 個 Bot 協同流水線。
1. 值班員讀商品與訂單表發晨報，**卡死唯讀紅線，嚴禁改價改庫存或發信退款**。
2. 細分專崗：內容抓流量，庫存盯週轉缺貨，售後查履約並草擬回覆。
3. 值班員升主管，產出存至 `/workspace/ecommerce-ops/日期/`。
4. 業務聯動：爆款剩 3 天庫存時，內容停推，售後備好話術，主管決策。

別貪大，**涉及資金、庫存與外部發信的操作全部鎖定人工審批**。

### 鐵柱的開源知識庫 Bot

鐵柱AGI（@cgnot996）搭常駐 Bot 維護 awesome-grok-bot 知識庫。
1. 定期巡檢 X 平台推文、官方更新記錄與社群動態。
2. 分類收錄新玩法、課程及官方文件。
3. 宣發前已自動收錄資料；2026 年 8 月突破 130+ Star（作者自述，未核），獲官方表單邀請。

常駐 Bot 適合做**長效資料檢索與文件歸檔**，省去重複勞動。
