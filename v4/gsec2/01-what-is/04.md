## 選型對照：Grok Bot 與主流常駐 Agent 橫向對比

選常駐 Agent 看圖省心還是折騰。**開箱整機**免運維但卡額度，組裝機自由但**環境報錯得自己修**。

| 產品 | 底座與門檻 | 特點與適用場景 |
| - | - | - |
| Grok Bot | 共享 Linux 雲端電腦。2026-10-12 起執行 The X Subscription（Premium $30、Super $100、Ultra $200/月），**Plus 檔不含 Bot**；客戶端 v0.70.2 配獨立郵箱與連線卡片 | 7×24 小時常駐，支援例程與技能，跨 Bot 非同步交接文件並調 X 檢索。適合免運維協同與巡檢對帳 |
| OpenAI dots | 個人常駐雲端電腦，ChatGPT Pro 檔包含 | 基於 GPT-6 Astra（2026-09-30 發表），常駐後台連 4000 多個外掛，主打日常伴隨與輕量代辦 |
| Manus Cue | 獨立雲端電腦，處於早期體驗階段 | 2026-09-29 鐵柱上手體驗；原生配獨立郵箱、電話與錢包跑腿採購，自主權極高但伴隨操作風險 |
| Meta Muse | Meta 託管雲端代理 | 諾鴨船長評測偏家庭生態，深度綁定 Meta 社交網路與硬體，適合家庭日常輔助 |
| Hermes | 本地或私服自建 | 自由換開源模型無額度限制，適合本地敏感資料流水線，**需自己動手配環境排錯** |
