## 多 Bot 文件交接約定與目錄規劃

### 文件協作模式

Bot 間讀不了聊天記錄，**多 Bot 協作的唯一通道是共享磁盤文件**。提示詞只需傳入上一棒文件路徑，詳見 [《4.6 虛擬機器、記憶與備份》](https://jcng5q8n0f3z.feishu.cn/wiki/KUggwkhqqiRyxZkwTLhcrCU2ncg)。

1. 整理員抓取生成 `tweets.md`
2. 分析師提煉輸出 `profile.md`
3. 設計師依畫像生成 `design.md`
4. 工程師讀設計建構程式碼

### 目錄規劃

建機之初定好目錄，免得多 Bot 把文件寫亂。

| 目錄路徑 | 存放內容 | 寫入規範 |
| --- | --- | --- |
| `/workspace/handoff/` | 中間產物 | 統一 Markdown 或 JSON，帶任務前綴 |
| `/workspace/projects/` | 專案程式碼與資產 | 按項目分獨立子目錄，關聯 Git 倉庫 |
| `/workspace/tools/` | 本地自寫指令碼 | 僅留無密鑰原始碼，排查後同步備份倉 |
| `~/.env` 或本地文件 | API 密鑰 | 僅保存在本地，**嚴禁提交程式碼倉或在會話打印** |

### 磁盤清理與 Disk Saver

系統報 `Computer is low on disk space` 或 `Computer is critically low on disk space` 警告，去側邊欄點 **Disk Saver** 的「Go to Disk Saver」看清理建議。**未經確認它絕不擅自刪除文件**，拒絕清理現有文件就原樣保留。
