## 容易踩的坑

### 憑證安全與權限認知
- **別在聊天框貼密鑰或密碼**。網頁端人工鍵入，CLI Token 存 `~/.env`，指令碼走環境變數。
- **同帳號 Bot 共享 `/workspace` 與權限**，無資料隔離。敏感資產靠外部私有倉庫權限與人工審批隔離。

### 協作規範與依賴管理
- **Bot 間協作必須落地文件**。會話不互通，Bot A 必須將結果存成 Markdown 或 JSON。
- **全域依賴不持久**。用 `apt install` 與 `npm install -g` 裝的工具，遇電腦更新或點了 Recover、Reset 都會清空，需備恢復指令碼。
- `node_modules` 與 `.venv` 不備份，**恢復指令碼須含 `npm install` 或 `pip install -r requirements.txt`**。

### 運維操作與網路組態
- 介面顯示 `Reconnecting` **先等或重啟客戶端，別點 Reset**。直接 Reset 會重建機器並丟掉改動。
- **別私加 crontab**。定時任務須統一列清單，交由 Git 倉庫維護。
- 開「通過當前電腦路由流量」後**長連線不自動切**。IP 沒變就把請求行程停掉重跑。
