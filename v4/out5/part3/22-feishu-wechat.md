# 第 22 章 接入飛書與微信

不用公網 IP 和自建伺服器，就能把 Grok Bot 安全接入飛書與微信。

The X Subscription（2026年10月12日生效）按周扣額度，**群聊必須配訊息過濾**，否則閒聊會耗光整週額度。

- **飛書多 Bot 協同**：走官方 Python SDK 長連線與「飛書應用管家」樣板。
- **微信 ClawBot 直連**：靠官方「微信ClawBot」外掛和 iLink 介面。
- **微信快捷指令收錄**：借蘋果快捷指令與 Webhook 歸檔記錄。

## 接入通道對比與技術選型

**三種接入方式全都不需要公網 IP**。

- 飛書多 Bot 通道：用於團隊辦公與群聊派工。走官方 WebSocket 長連線出站，支援富文本與卡片，群內僅回應 @ 保護額度。
- 微信 ClawBot 通道：用於個人日常隨身助理與排程。走 iLink 長輪詢，僅支援純文字，靠白名單單聊避免無效喚醒。
- 微信快捷指令通道：用於圖文與音訊資產入庫。走 Webhook 單向推送並返回回執，按需觸發，無訊息不產生額外消耗。

## 團隊接入飛書：多 Bot 協同與飛書應用管家

### 飛書長連線與門鈴觸發器機制

走長連線出站，**免去公網 IP、證書和開放端口**。

1. 飛書自建應用：負責群聊與單聊收發。
2. 雲端轉發程式：後台監聽長連線並轉交。
3. 門鈴觸發器：喚醒 Bot 並調 SDK 回覆。

怕重複組態，用「飛書應用管家」**掃碼自動建應用**。

### 怎麼做：從單 Bot 跑通到多 Bot 協同

#### 掃碼建首個 Bot（文章主編）
1. 私聊讓 Bot 調飛書 SDK 掃碼建應用。**該連結為一次性憑證且僅限管理員使用，切勿點他人連結或轉發。**
2. 瀏覽器打開連結點「建立」並確認權限，憑證自動回傳。
3. 收到飛書測試訊息後回覆一條，**Bot 自動將你的 Open ID 寫入白名單**。

#### 建立門鈴例程
1. 點選 Bot 名稱進 [help_grok-bot_routines.md](file:///workspace/grok-bot-learn/v3/src/help_grok-bot_routines.md) 的 **Details** 面板。
2. 在例程建 Webhook 門鈴，獲取 POST to 地址與 key。
3. **必須在 Bot 彈出的加密輸入框提交憑證**，避免明文洩露。單聊發測試文本，Bot 正常回復即跑通。

#### 批量建應用與群聊協同
1. 匯入樣板 `https://x.ai/bot/AJpUlCwa8tyMX7L5UHnuY`。登記表與恢復指令碼存 Git 私有倉庫，不存明文密鑰。
2. 向管家下令批量生成掃碼連結（**每連結 1 小時有效**），掃碼並在加密窗填 key，管家自動拉起轉發。
3. 建群拉入各 Bot，**發 `@所有人` 確認彙報管轄範圍**；`@文章主編` 調 `虛擬機器服務管家`，服務管家發登記表進群即完成協同。

#### 交互安全
- **指令來源校驗**：僅回應群內白名單管理員的直接指令。
- **飛書卡片確認**：改組態、寫庫或重啟等高危操作推送帶「同意」與「駁回」按鈕的卡片，**在飛書內點選即可二次授權**。

### 做到什麼程度算好

- **端到端耗時低於 1 秒**：發訊息基本秒回。
- **群聊訊息精準分流**：閒聊靜默，單獨 @ 誰誰回，@所有人按職責彙報不搶答。
- **高可用自愈**：退出 5 秒內拉起，每 5 分鐘巡檢假死，強殺行程約 9 秒恢復。

## 個人接入微信：微信 ClawBot 外掛直連

走官方 iLink 介面（`ilinkai.weixin.qq.com`），純出站長輪詢，**不開放公網端口，合規且無封號風險**。

### 三步完成接入

1. **發送提示詞**：電腦端向主 Bot 發送下方指令，等待自動生成通信元件。
::: details 三步完成接入
```text
我想把你接到我的微信上，讓我能在微信裡直接給你發訊息、收到你的回覆。請按下面的思路做，每做完一步告訴我結果，需要我操作的地方停下來等我。

1、先調研方案：騰訊「微信ClawBot」外掛用的是 iLink 介面（ilinkai.weixin.qq.com）。請確認怎麼用 getupdates 長輪詢收訊息、怎麼用 sendmessage 回訊息。整個程式只走出站請求，不要開公網端口。

2、在 Grok Bot 裡建一個由 webhook 觸發的 routine，名字可以叫「微信下旨入口」。建好後告訴我去 routine 面板複製 Webhook URL 和 key，然後彈出加密彈框讓我填進去，不要讓我在聊天裡發明文。

3、在你的雲端電腦上寫一個小轉發程式：收到微信訊息後 POST 給這個 routine；你處理完以後，用一個 reply 指令碼把回覆發回微信，同時在我們的主聊天裡同步一份。

4、等我在手機微信裡啟用 ClawBot 外掛以後，生成二維碼讓我用手機掃碼確認，同時給我一個可以在微信裡直接打開的備用連結。二維碼大約 5 分鐘有效。

5、綁定成功後，提醒我先在 ClawBot 對話裡發一句話，因為回覆要用到這條訊息帶的 context_token。

6、規則：只認綁定的這一個人，別人的訊息不處理；回覆一律用純文字，不要用 Markdown，因為微信不渲染 Markdown。

7、最後告訴我：雲端電腦重啟以後，怎麼把轉發程式重新拉起來；如果遇到錯誤碼 -14（憑證過期），提醒我重新掃碼。
```
:::
2. **組態密鑰**：打開主 Bot 的「微信下旨入口」例程，複製 Webhook 的 **POST to** 和 **key** 提交到加密框。
3. **綁定與啟動**：
   - 微信版本須滿足 **iOS ≥ 8.0.70，Android ≥ 8.0.69**，在「設定-外掛」啟用「微信ClawBot」。
   - 對電腦 Bot 發「外掛開好了」，微信掃碼授權（二維碼 5 分鐘內有效）。
   - **必須主動向微信 ClawBot 發首條訊息**（如“你好”），獲取 `context_token` 啟動回包。

### 驗收標準

- **雙向同步**：微信端秒級回覆，電腦端實時存檔。
- **子 Agent 排程**：在微信直接派發推特檢索、影片轉錄任務。
- **安全隔離**：未綁定的微信號無法喚醒。

## 微信內容入庫：快捷指令打通聊天記錄與多媒體

通過快捷指令把合併轉發的 ZIP 包傳給臨時網盤，**再推給 Grok Bot 的 Webhook 自動歸檔**。

### 組態與操作

1. 在 Grok Bot 對話視窗發提示詞建立例程：
```text
幫我建立一個 Webhook 觸發的例行任務。快捷指令會用 POST 請求發來一個 JSON，裡面只有一個欄位 info。info 可能是我輸入的文字，也可能是一個文件下載連結，比如微信聊天記錄壓縮包、截圖、錄音。收到後：如果是連結就先下載文件再讀取，壓縮包先解壓；然後整理出要點，收錄進知識庫，最後給我一份回執，寫清楚收錄了什麼、存在哪裡。
```
在詳情頁 Routine 列表裡，**複製 Webhook 的 POST to 地址與 key 密鑰**。

2. 匯入快捷指令：`https://www.icloud.com/shortcuts/2b77155d7c744110a0f0f9ef1bdc42bf`。

3. 填入 POST to、key 和圖床 ID。`filebin.net` 文件存 7 天，**ID 須設 8 位以上隨機字元**（如 `kb7x9q2m`）防覆蓋洩露；**分享前務必清空這三項**。

4. 微信多選聊天記錄，合併轉發到其他應用，選快捷指令「發送給知識庫 Bot」中的「接收轉發」。未接收轉發時會讀剪貼板，也能選「截圖」或「錄音」直傳。

### 驗收標準

- **多媒體解析完整**：解壓並分類圖片、文件與語音（如 13 個設計靈感網站按整站、App、元件建索引）。
- **回執規範**：標清主題要點、筆記儲存路徑與原始 ZIP 歸檔路徑。

參考：[《微信聊天記錄打通 Grok Bot：快捷指令進階版》](https://jcng5q8n0f3z.feishu.cn/wiki/IwrfwYt1ti0aDWk3YEdcGyQRnUb)。

## 容易踩的坑與排查方案

### 1. 飛書權限組態不足導致群訊息無法接收

- **坑點**：單聊正常但群內 `@` 沒反應也沒記錄，因初選 7 項權限，漏了「獲取群組中所有 @機器人的訊息」。
- **解法**：走 SDK 掃碼生成補權連結，管理員確認擴到 14 項，**無需重新發版**。

### 2. 飛書群聊過濾規則誤判與長連線斷線重推

1. 漏訊息與搶答：飛書 `@所有人` 不在 mention 陣列，不驗 ID 又會全員搶答。**指令碼必須卡準目標 ID，只回應「`@自己`」或「`@所有人`」**。
2. 重複回覆：網路恢復後官方會自動補推，**千萬別手動二次補發**。

### 3. 跨 Bot 呼叫的信任鏈與授權卡片缺失

1. 群裡 Bot 互調沒反應，是**跨 Bot 訊息預設不可信**，全卡在私聊等確認。
2. 轉發層配白名單認管理員 Open ID；高危操作推**帶同意/駁回的飛書卡片**確認。

### 4. 虛擬機器 Python 執行環境路徑錯誤

- 指令碼報錯提示找不到 `lark-oapi`，通常是組態守護任務時**誤用了系統預設的 `/usr/bin/python3`**。
- 在啟動指令碼、Supervisor 和定時任務裡，**必須寫死虛擬環境的絕對路徑**（如 `/home/user/venv/bin/python3`），別直接調系統全域環境。

### 5. 微信 ClawBot 二維碼失效與錯誤碼 -14

- 二維碼**只有 5 分鐘有效期**，超時會失效，出來後趕緊用手機掃。
- 後台報錯誤碼 **`-14`** 是憑證過期了，重新生成二維碼讓管理員再掃一次就行。

### 6. 微信訊息格式混亂與 Markdown 渲染失敗

- 微信**不解析 Markdown**，星號、反引號和標題符號都會直接露出來。
- 在接入提示詞或轉發指令碼里加過濾，**統一轉成帶換行的純文字**再發給微信。

### 7. 微信合併轉發 ZIP 缺少未載入的多媒體附件

微信不存原文件，沒點開載入的不會打進壓縮包，解壓就會丟圖片。

1. 轉發前，**逐個點開需要保存的圖片和文件**。
2. 等本地完全載入好，再去封裝轉發。

### 8. 臨時網盤的命名衝突與隱私洩露風險

`filebin.net` 沒帳號體系，ID 太簡單會撞車，導致報錯或下到別人的文件。用的時候注意：

- 圖床 ID **必須設為 8 位以上隨機字串**。
- 別傳密碼、身份證等隱私內容。
- 分享快捷指令前，**刪掉自己的專屬 ID 與 Webhook 密鑰**。

### 9. The X Subscription 統一訂閱下的額度防耗控制

群員閒聊會觸發例程空轉，**一到兩天就會耗盡周額度導致 Bot 停止回應**。

2026 年 10 月 12 日起 The X Subscription 按周從共享池扣額度。Plus 檔（$8/月）沒有 Grok Bot，只有 Premium（$30/月，4x 額度）、Super（$100/月，15x 額度）與 Ultra（$200/月，50x 額度）包含。

防耗抓兩點：
1. **僅在精準提及（`@自己`）或特定管理員指令時觸發 Webhook**。
2. 嚴禁全群無差別監聽，避免組態高頻短週期輪詢。

詳細規則參考 [help_grok-bot_plans.md](file:///workspace/grok-bot-learn/v3/src/help_grok-bot_plans.md) 與 [help_grok-bot_routines.md](file:///workspace/grok-bot-learn/v3/src/help_grok-bot_routines.md)。

## 實戰案例覆盤

### 飛書多 Bot 協同（鐵柱AGI）
沒公網 IP 也能跑協同，**核心是用出站長連線免打洞**。
1. **批量註冊**：飛書 Python SDK 掃碼授權，管家 Bot 讀 Git 備份表，託管主編、記帳與虛擬機器 3 個 Bot 的密鑰和 Webhook。
2. **安全確認**：群內僅回應 `@自己` 或 `@所有人`。**高敏感操作由 Bot 推卡片按鈕人工授權**。

### 微信 ClawBot 隨身台（Kin）
微信內排程推特運營與文案提取 Bot，**走官方外掛長輪詢能防封號**。
1. 給 7×24 小時雲端電腦發提示詞，調騰訊 iLink（`ilinkai.weixin.qq.com`）跑通 `getupdates` 輪詢與 `sendmessage` 指令碼。
2. 彈窗交接 Webhook 和密鑰，掃碼發首條訊息拿到初始 `context_token`。
3. **踩坑點**：**微信回覆必須強制轉純文字**，剝除 Markdown 符號。

### 微信圖文歸庫流水線
微信沙盒禁了整包直傳，**用臨時網盤當中轉可繞過限制**。
1. **中轉上傳**：Mac 或 iPhone 用「合併轉發」匯出聊天 ZIP 包，快捷指令自動傳到 `filebin.net`。
2. **自動歸檔**：快捷指令拼 JSON 發給 Grok Bot 的 Webhook，解壓歸檔「13 個設計靈感網站」等圖文。
3. **驗收標準**：**必須輸出帶路徑與摘要的結構化回執**。

## 做完怎麼驗收

### 飛書
1. **訊息回應**：私聊 1 秒內回覆；群聊發普通文字靜默，單獨 `@文章主編` 回應，`@所有人` 各 Bot 依次彙報。
2. **權限與自愈**：後台開齊 14 項事件權限並支援卡片授權；手動殺掉行程，5 至 10 秒內自動拉起。

### 微信
1. **環境與握手**：微信高於 iOS 8.0.70 或 Android 8.0.69 並啟用外掛；掃碼首條用 `context_token` 回覆且無 Markdown 亂碼。
2. **攔截與報錯**：未綁定帳號直接忽略；重啟後自動拉起，**遇到錯誤碼 `-14` 提示重新掃碼**。

### 快捷指令
1. **入庫操作**：填好 Webhook、Bearer 密鑰及 8 位以上圖床 ID；微信先點開載入附件再合併轉發，也能獨立喚醒。
2. **輸出與對帳**：**回執須包含提要、筆記路徑與留存路徑**；在方案頁核查用量，避免持續空轉扣費。
