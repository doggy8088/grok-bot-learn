# Node.js 與 npm

<ToolMeta id="nodejs" />

Node.js 與 npm 是前端及各類 AI CLI 的執行基礎，適合為 Bot 提供 **現代命令列工具的執行環境**。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝好 Node.js 與 npm（https://github.com/nvm-sh/nvm），以後執行前端項目和各類命令列工具用它。
````

</div>

## 需要你自己做的事

- 確認雲端電腦網路連通，無需準備外部帳號。
