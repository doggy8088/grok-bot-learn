# Gemini CLI

<ToolMeta id="gemini-cli" />

Google 開源的終端 AI Agent，適合 **付費使用者與 Google Cloud 項目使用者** 進行終端交互與開發協作。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 Gemini CLI（https://geminicli.com/docs/get-started/installation/），以後終端交互和開發協作用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## 需要你自己做的事

- 準備付費 Google 帳號或 Google Cloud 項目帳號。
- 在瀏覽器打開 Bot 發送的授權連結完成認證。
