# Cursor CLI

<ToolMeta id="cursor-cli" />

Cursor 官方命令列 Agent，適合 **在雲端電腦執行小範圍程式碼修改**，將 Bot 額度留給全域決策。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上裝好 Cursor CLI（https://cursor.com/docs/cli/installation），以後小範圍程式碼修改用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## 需要你自己做的事

- 準備 Cursor 帳號或相關授權憑證。
- 在瀏覽器打開 Bot 發送的授權連結完成登錄。
