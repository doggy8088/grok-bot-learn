# MCP 連線器

<ToolMeta id="mcp-connectors" />

MCP 連線器打通了外部服務與模型的交互通道，適合讓 Bot **直接呼叫外部工具與雲端資料** 完成複雜協同。

結論是：該工具僅用於讓 Bot 直接呼叫外部工具與雲端資料完成複雜協同。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上接入 MCP 連線器（https://docs.x.ai/grok/connectors），以後呼叫外部工具和同步雲端資料用它。需要第三方授權時把連結發給我，需要填密鑰時請提醒我自己填。
````

</div>

## 需要你自己做的事

- 在瀏覽器訪問連線器控制頁面並準備待連線帳號。
- 根據提示自行填入目標服務的地址或授權密鑰。
