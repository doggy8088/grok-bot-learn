# Antigravity CLI（agy）

<ToolMeta id="agy" />

Google 官方終端 Agent，適合 **影片理解、長文寫作與程式碼修改**，支援直接讀取影片文件。

結論是：agy適合影片理解、長文寫作與程式碼修改，支援直接讀取影片文件。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝組態 Antigravity CLI（https://antigravity.google/docs/getting-started/），以後影片理解、長文寫作與程式碼修改用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## 需要你自己做的事

- 準備 Google 帳號。
- 在瀏覽器打開 Bot 發送的授權連結完成認證。
