# Pi Coding Agent

<ToolMeta id="pi" />

極簡且高度可擴充的終端寫程式 Agent，適合 **通過擴充、技能與提示樣板深度客製化** 專屬開發工作流。
適合喜歡通過擴充、技能與提示樣板客製化專屬開發流的極客開發者。

結論是：該工具僅用於通過擴充、技能與提示樣板，深度客製化極簡、高擴充的專屬終端寫程式 Agent 工作流。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 Pi Coding Agent（https://pi.dev），以後客製化開發工作流和寫程式碼用它。需要填密鑰時請提醒我自己填。
````

</div>

## 需要你自己做的事

- 準備對應模型服務商的 API Key。
- 收到提示後自行將密鑰寫入私密組態檔。
