# DeepSeek Harness

<ToolMeta id="deepseek-harness" />

DeepSeek 官方開源的 **「一切皆外掛」架構 Agent**，支援桌面端與 Web UI。目前處於開發者預覽階段，適合用於 **程式碼編寫**、**調研分析**、**日常辦公** 與 **定時任務擴充**。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝組態 DeepSeek Harness（https://github.com/deepseek-ai/deepseek-harness），以後日常辦公、調研、寫程式碼和跑定時任務用它。需要組態 DeepSeek API Key 時請停下來提醒我自己填。
````

</div>

## 需要你自己做的事

- 準備好 DeepSeek API Key
- 待 Bot 安裝完畢後，在設定中自行填入 API Key
