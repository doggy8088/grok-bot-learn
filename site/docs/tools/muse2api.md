# muse2api

<ToolMeta id="muse2api" />

社群開源的 muse.ai 逆向封裝項目，適合在 **雲端電腦** 上通過 OpenAI 相容介面直接呼叫網頁端免費額度進行對話、生圖和生影片。

結論是：該工具僅用於在雲端電腦上通過相容介面實作對話、生圖與生影片。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上部署 muse2api（https://github.com/czg86389-hub/muse2api），以後呼叫多模態介面進行對話、生圖和生影片用它。需要填密鑰時請提醒我自己填。
````

</div>

## 需要你自己做的事

- 準備 muse.ai 帳號並在雲端電腦瀏覽器中完成登錄。
- 根據提示自行填入通信密鑰與登錄狀態資料。
