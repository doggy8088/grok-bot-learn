# 飛書 CLI（lark-cli）

<ToolMeta id="lark-cli" />

飛書官方命令列工具，適合讓 Bot 以個人身份在 **雲端電腦** 上操作飛書雲文件、多維表格、雲端硬碟和知識庫。
Bot 以個人身份在雲端電腦中操作飛書雲文件、多維表格、雲端硬碟與知識庫。
適合需要 Bot 以個人身份在雲端電腦管理飛書文件、表格與雲端硬碟資產的使用者。

結論是：飛書官方命令列，適合讓 Bot 以個人身份在雲端電腦上操作雲文件、多維表格、雲端硬碟和知識庫。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝組態飛書 CLI（https://github.com/larksuite/cli），以後操作飛書雲文件、多維表格和雲端硬碟用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## 需要你自己做的事

- 準備飛書個人帳號。
- 打開驗證連結輸入終端給出的設備碼確認授權。
