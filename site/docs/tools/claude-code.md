# Claude Code

<ToolMeta id="claude-code" />

Anthropic 官方終端寫程式 Agent，適合 **程式碼庫閱讀、多文件修改與命令執行**，支援後台自動更新。

## 發給 Bot 的提示詞

複製下方整段內容發送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登錄或組態密鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上裝好 Claude Code（https://code.claude.com/docs/en/setup），以後閱讀程式碼庫和多文件修改用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## 需要你自己做的事

- 準備 Claude 訂閱或 Anthropic Console 帳號。
- 在瀏覽器打開 Bot 發送的授權連結完成認證。
