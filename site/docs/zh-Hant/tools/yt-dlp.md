# yt-dlp

<ToolMeta id="yt-dlp" />

yt-dlp 是支援上千個站點的命令列音影片下載工具，適合讓 Bot **批次下載影片或抽取音訊** 以供後續轉寫處理。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登入或組態金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 yt-dlp（https://github.com/yt-dlp/yt-dlp），以後批量下載音影片和提取音訊用它。
````

</div>

## 需要你自己做的事

- 準備需要下載的目標媒體連結。
- 遇到需登入的站點時匯出對應 Cookie 檔案備用。
