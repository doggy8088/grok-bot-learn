# Playwright

<ToolMeta id="playwright" />

Playwright 是微軟開源的自動化庫，適合讓 Bot 執行 **批次網頁截圖與渲染抓取**，無需手動耗費瀏覽器互動額度。

## 發給 Bot 的提示詞

複製下方整段內容傳送給你的 Grok Bot，它會在雲端電腦上自動安裝並驗證，遇到登入或組態金鑰時會暫停等待你操作。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 Playwright（https://playwright.dev/python/docs/intro），以後網頁渲染、截圖和抓取任務用它。
````

</div>

## 需要你自己做的事

- 確認雲端電腦具備 Python 執行環境。
