# FFmpeg

<ToolMeta id="ffmpeg" />

FFmpeg はマルチメディア低層処理の中核ツールであり、Bot に**動畫・音聲のトランスコード、圧縮、フレーム切り出し、音聲抽出**を任せるのに適しています。
