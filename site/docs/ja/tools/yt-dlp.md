# yt-dlp

<ToolMeta id="yt-dlp" />

yt-dlp は數千以上のサイトに対応したコマンドライン動畫・音聲ダウンロードツールで、Bot に**動畫の一括ダウンロードや音聲の抽出**を行わせ、その後の文字起こし処理などに活用するのに適しています。

## Bot に送信するプロンプト

以下の內容をすべてコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われます。ログインやキーの設定が必要な場合は一時停止して操作待ちとなります。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 yt-dlp（https://github.com/yt-dlp/yt-dlp），以後批量下載音影片和提取音訊用它。
````

</div>

## 自身で行う作業

- ダウンロード対象となるメディアのリンクを準備する。
- ログインが必要なサイトの場合は、対応する Cookie ファイルをエクスポートして用意しておく。
