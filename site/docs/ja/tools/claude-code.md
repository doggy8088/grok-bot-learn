# Claude Code

<ToolMeta id="claude-code" />

Anthropic 公式のターミナルコーディング Agent。**コードベースの読解、複數ファイルの編集、コマンド実行**に適しており、バックグラウンドでの自動更新をサポートしています。

結論として、Claude Code はコードベースの読解、複數ファイルの編集、コマンド実行に適しており、バックグラウンドでの自動更新に対応しています。

## Bot に送信するプロンプト

以下の內容をすべてコピーしてあなたの Grok Bot に送信すると、クラウド PC 上で自動的にインストールと検証が行われます。ログインやキー設定が必要になった場合は一時停止し、あなたの操作を待ちます。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上裝好 Claude Code（https://code.claude.com/docs/en/setup），以後閱讀程式碼庫和多文件修改用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## ご自身で行うこと

- Claude のサブスクリプション、または Anthropic Console アカウントを用意する。
- ブラウザで Bot から送信された認証リンクを開き、認証を完了する。
