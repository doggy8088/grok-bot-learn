# Codex CLI

<ToolMeta id="codex" />

OpenAI 公式ターミナルコーディング Agent。**コード修正、スクリプト実行、畫像生成・畫像確認**に適しており、ChatGPT のサブスクリプション利用枠を直接使用できます。
コード修正、スクリプト実行、畫像生成・畫像確認を行いたい ChatGPT サブスクリプションユーザーに最適です。


## Bot に送信するプロンプト

以下の內容をすべてコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われ、ログインやキー設定が必要な場合は一時停止して操作を待ちます。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上裝好 Codex CLI（https://developers.openai.com/codex/cli），用我的 ChatGPT 帳號登入，以後寫程式碼、跑指令碼和生圖用它。需要我授權時把連結發給我。
````

</div>

## ご自身で行う作業

- ChatGPT アカウントを用意し、デバイスコードログイン権限が有効になっていることを確認します。
- ブラウザで Bot から送信されたデバイスコードのリンクを開き、確認を完了します。
