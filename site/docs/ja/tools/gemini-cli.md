# Gemini CLI

<ToolMeta id="gemini-cli" />

Googleがオープンソースとして公開しているターミナルAI Agentで、**有料ユーザーおよびGoogle Cloudプロジェクトユーザー**によるターミナル操作や開発連攜に適しています。

結論として：本ツールは、有料ユーザーおよびGoogle Cloudプロジェクトユーザーがターミナルでの対話や開発連攜を行うことのみを目的としています。

## Botに送信するプロンプト

以下の內容をすべてコピーしてGrok Botに送信してください。クラウドPC上で自動的にインストールと検証が行われ、ログインやキー設定が必要になった場合は一時停止して操作を待ちます。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 Gemini CLI（https://geminicli.com/docs/get-started/installation/），以後終端交互和開發協作用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## 自身で行うこと

- 有料GoogleアカウントまたはGoogle Cloudプロジェクトアカウントを用意する。
- ブラウザでBotから送信された認証リンクを開き、認証を完了する。
