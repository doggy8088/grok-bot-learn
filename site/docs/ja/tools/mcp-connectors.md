# MCP コネクタ

<ToolMeta id="mcp-connectors" />

MCP コネクタは外部サービスとモデル間の通信チャネルを開通させ、Bot が**外部ツールやクラウドデータを直接呼び出して**複雑な連攜を行うのに適しています。

結論として：本ツールは、Bot が外部ツールやクラウドデータを直接呼び出して複雑な連攜を行う目的のみに使用されます。

## Bot に送信するプロンプト

以下の內容を丸ごとコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われ、ログインやキー設定が必要な場合は一時停止して操作を待機します。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上接入 MCP 連線器（https://docs.x.ai/grok/connectors），以後呼叫外部工具和同步雲端資料用它。需要第三方授權時把連結發給我，需要填密鑰時請提醒我自己填。
````

</div>

## ご自身で行う作業

- ブラウザでコネクタの管理ページにアクセスし、接続対象のアカウントを準備する。
- 指示に従って対象サービスのアドレスや認証キーを自分で入力する。
