# DeepSeek Harness

<ToolMeta id="deepseek-harness" />

DeepSeek 公式がオープンソースで提供する**「すべてがプラグイン」アーキテクチャの Agent** で、デスクトップおよび Web UI をサポートしています。現在は開発者プレビュー段階にあり、**コード作成**、**調査・分析**、**日常業務**、**定期タスクの拡張**に適しています。

## Bot に送信するプロンプト

以下の內容をすべてコピーして Grok Bot に送信してください。クラウド PC 上で自動的にインストールと検証が行われます。ログインやキーの設定が必要な場面では一時停止し、あなたの操作を待ちます。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝組態 DeepSeek Harness（https://github.com/deepseek-ai/deepseek-harness），以後日常辦公、調研、寫程式碼和跑定時任務用它。需要組態 DeepSeek API Key 時請停下來提醒我自己填。
````

</div>

## ご自身で行う作業

- DeepSeek API Key を用意する
- Bot のインストール完了後、設定畫面で各自 API Key を入力する
