# 飛書 CLI（lark-cli）

<ToolMeta id="lark-cli" />

飛書公式のコマンドラインツール。Bot が個人アカウントとして **クラウドPC** 上で飛書ドキュメント、Base（多次元テーブル）、クラウドドライブ、ナレッジベースを操作するのに適しています。
Bot が個人アカウントとしてクラウドPC內で飛書ドキュメント、Base、クラウドドライブ、ナレッジベースを操作します。
Bot が個人アカウントとしてクラウドPC上で飛書ドキュメント、Base、ドライブの資産を管理することを希望するユーザーに適しています。


## Bot に送信するプロンプト

下記の內容をそのままコピーして Grok Bot に送信してください。クラウドPC上で自動的にインストールと検証が行われます。ログインやキー設定が必要になった場合は一時停止し、あなたの操作を待ちます。

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝組態飛書 CLI（https://github.com/larksuite/cli），以後操作飛書雲文件、多維表格和雲端硬碟用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## ユーザー自身で行う作業

- 飛書の個人アカウントを用意する。
- 認証リンクを開き、ターミナルに表示されたデバイスコードを入力して承認を完了する。
