# 第 2 章 プランとサブスクリプション：まずは適切なグレードを選ぶ

初心者のプラン購入時によくある3つの落とし穴があります。
- 一番安いエントリープランを購入したものの、クライアントを開いてもエージェントの入口が見當たらない。
- **Cursor のサブスクリプションと SuperGrok の週間利用枠は合算されず、システムはより高いグレード側のみを適用します。**
- モバイルアプリ內でアップグレードをタップしてもプランを切り替えられず、既存のサードパーティ製モデルの利用枠まで失ってしまう。

Grok Bot の実行は利用枠に依存しています。**週間の利用枠を使い果たし、かつオンデマンド保護を設定していない場合、クラウド自動化タスクは即座に停止します。**

公式は2026年10月12日より「The X Subscription」統一サブスクリプションを匯入しており、無料プランと4つの有料プランに分かれています。


![プランとサブスクリプション：まずは適切なグレードを選ぶ](/info/02-plans.png)

## Grok Bot を使うにはどのサブスクリプションプランを購入すべきか？ {#統一訂閱全貌-the-x-subscription-的四檔與免費檔}

**統一サブスクリプションは Plus、Premium、Super、Ultra の4グレードに分かれており、Plus プランには Grok Bot が一切含まれていないため、自動化タスクを実行するには月額30ドルの Premium プラン以上を選択することが必須となります。**

![統一サブスクリプション全貌：The X Subscription の4グレードと無料プラン](/info/02-plans-s1.png)

### 概要

2026年10月12日より「The X Subscription」に統合され、年払いは月払いの10倍の価格設定となっています。

1ドルあたりの利用量で換算すると（Plus を基準1とし、Premium は約1.07、Super は約1.2、Ultra は約2.0。※著者自身の記述、未検証）、上位グレードほど自社製モデルのコストパフォーマンスが高くなります。

| プラン | Web版 月払い / 年払い | Grok Bot |
| :--- | :--- | :--- |
| **無料プラン** | $0 | 7日間の利用枠トライアル |
| **Plus** | $8/月（実質約$7）/ $80/年 | 含まれない |
| **Premium** | $30/月 / $300/年 | 含まれる（利用の最低條件） |
| **Super** | $100/月 / $1000/年 | 含まれる |
| **Ultra** | $200/月 / $2000/年 | 含まれる（最大クォータ） |

**Plus プランには Grok Bot および Cloud agents が一切含まれていません**。自動化タスクを実行するには、まず月額30ドルの Premium プランを選ぶ必要があります。無料トライアルは有効期間が7日間に制限されており、タスクの規模・ステップ數・トークン數に応じて利用枠が消費されます。負荷の高いタスクでは1回で使い果たしてしまう可能性があり、消費後のリセットはありません。

### 手順

**加入はモバイルアプリでの決済を避け、Web版から行うことを推奨します。**

1. ブラウザで統一サブスクリプションページ [grok.com/com/overlay/subscribe](https://grok.com/com/overlay/subscribe?from=/) にアクセスします。
2. 業務で使用する X または Grok アカウントにログインします。
3. Premium プランを選択します（月額30ドル。コミュニティでは初月50%オフの15ドルキャンペーンの事例もありましたが、実際の決済畫面の表示に準じます）。
4. いつでもプラン変更やツールの乗り換えができるよう、**年払いには直接チェックを入れず、月払いを選択します**。
5. 対応している國際クレジットカード、デビットカード、またはWeb版の Apple Pay、Google Pay で支払います。
6. Grok Bot クライアントを開いてログインし、メイン畫面でエージェントの作成および実行権限がアンロックされていることを確認します。

詳細な解説については、『[大一統 X サブスクリプション解説：新規ユーザーの選び方、既存サブスクは切り替えるべきか？徹底解説](https://jcng5q8n0f3z.feishu.cn/wiki/Myw6wFW8EicOiRkoEAXcVJqinee)』および『[鐵柱ポストまとめ①：加入、プランと利用枠](https://jcng5q8n0f3z.feishu.cn/wiki/PCZIw5IqgiZLjTkXqNncpxannpc)』をご參照ください。

### 達成基準

Grok Bot デスクトップクライアントを開き、**新規タスクにクラウド環境が割り當てられて実行でき、かつ請求ステータスが月額課金の Premium 狀態と表示されていれば**合格です。

## Grok Bot の週間利用枠プールはどのように決済・集計されるか？ {#每週共享用量池-額度結算與多端共用機制}

**サブスクリプションでは毎週一定の利用枠プールが提供され、複數デバイス間でリアルタイムに同期されます。公式モデルはWeb版、Bot、Cursor のコード補完でタスク量とステップ數に応じて共有プールから消費され、サードパーティ製モデルは定価に基づき個別に課金されます。**

![週間共有利用枠プール：利用枠決済とマルチデバイス共有メカニズム](/info/02-plans-s2.png)

### 概要

The X Subscription では毎週固定の利用枠プールが付與され、期限が來ると自動的にリフレッシュされます。**Grok Web版、Bot、Cursor の補完・Q&Aでこのプールを共有します**。Mac と iPhone で同一アカウントにログインしていれば利用枠はリアルタイムで同期され、デバイスを切り替えても二重に消費されることはありません。

| モデル種別 | 決済・集計ルール |
| :--- | :--- |
| 公式モデル | 共有プールに計上。Web版と Bot の雙方がここから消費され、消費速度はタスク量とステップ數のみに依存します。 |
| サードパーティ製モデル | **共有プールには計上されず**、Cursor 內で API 定価に基づき個別に課金されます。 |

システムの基底モデルは自動的に割り當てられ、一律「Grok Bot 利用量」と表記され、手動での選択や除外はできません。詳細は [Grok Bot モデル](https://cursor.com/cn/help/grok-bot/models.md) をご覧ください。

### 手順

最初の3日間で利用枠を使い切ってしまうのを防ぐため、日常的に次の3つのステップで計畫を立てます。

1. **週の初めにコアとなる重いタスクを実行する**。コアコードの作成、アーキテクチャの構築、複雑なロジックのデバッグを優先的に処理します。
2. **消費の激しい操作を避ける**。動畫の一括生成、高頻度のポーリング、複數 Bot の連攜は最も消費が激しくなります（※著者自身の記述、未検証）。動畫生成は Bot のワークフローに入れず、Web版で行うことを推奨します。
3. 注目すべきリセット週期。ダッシュボードに表示されている毎週のリセット日を把握しておき、リセット直前に餘りがある場合にデータ整理や詳細なコードレビューを集中的に行います。

### 達成基準

**日常的な自動化では、1日の平均消費量を10%〜15%程度に抑えるようにします**。毎週のリセット前日に約20%のバッファを殘し、利用枠不足のポップアップ警告が出ない狀態を維持できていれば、適切なペース配分といえます。

## Cursor と Grok を連攜して利用枠を共有するには？ {#授權互通-cursor-套餐與-supergrok-關聯規則}

**Cursor は Grok アカウントと直接連攜して利用枠をマッピングできます。連攜しても元のプランは変更されず、追加料金も発生しません。利用枠は両者のうち高いグレードが適用され（合算不可）、ペアリング後は永久に固定され、連攜解除や移行はできません。**

![認証の相互連攜：Cursor プランと SuperGrok の連攜ルール](/info/02-plans-s3.png)

### 概要

Cursor アカウントは Grok アカウントと直接連攜して利用枠を共有できます。**連攜する前に、まず3つの鉄則を確認してください。**

- 利用枠の同期のみでプランは不変：利用枠が直接マッピングされるだけで、現在の Cursor プランは変更されず、追加料金もかかりません。
- 利用枠は合算されず、上位グレードのみ有効：雙方の週間利用枠のうち、より高い方が適用されます（例：Cursor Pro に SuperGrok Plus を連攜すると Plus の利用枠に引き上げられます）。
- 連攜後は永久固定で解除不可：ペアリング完了後は、**自己操作であれカスタマーサポートへの問い合わせであれ、連攜の解除や認証の移行は一切できません。**

| Cursor サブスクリプション層 | 同等の連攜グレード | Grok Bot 週間利用量 |
| :--- | :--- | :--- |
| Cursor Pro | SuperGrok / X Premium+ | 基本週間利用量 |
| Cursor Pro+ | SuperGrok Plus | 十分な週間利用量 |
| Cursor Ultra | SuperGrok Heavy | 最大週間利用量 |
| Cursor プランなし | SuperGrok Lite | Grok Bot 提供なし（Lite グレードは権限なし、アップグレード後に連攜が必要） |

Grok Business のエンタープライズシートが割り當てられている場合、アカウントにすでに Bot 権限が付與されているため、**畫面上で連攜操作を行う必要は一切ありません。**

### 手順

個人アカウントの連攜はWeb版から行います。

1. ブラウザで利用枠を適用したい Cursor アカウントを使って Grok Bot Web版にログインし、メインアカウントに間違いがないことを確認します。
2. クイックスタートの入口 [cursor.com/bot/onboarding](https://cursor.com/bot/onboarding) を開きます。
3. 「Link Grok Account（Grok アカウントを連攜）」をクリックします（モバイル端末の場合はサブスクリプションページ內の同名ボタンをタップ）。
4. 遷移先で SuperGrok、SuperGrok Plus、SuperGrok Heavy、または X Premium+ を保持しているアカウントにログインして認証します。
5. クライアントの設定畫面に戻り、ステータスを確認します。**新しい利用枠が同期されるまでに最大24時間かかる場合があります。その間、連攜ボタンを再度クリックしたり、連攜解除を試みたりしないでください。**

完全なルールについては、公式ドキュメント [Grok Bot に SuperGrok を連攜する](https://cursor.com/cn/help/grok-bot/supergrok.md) をご覧ください。

**エンタープライズシートが割り當てられているユーザーは、追加の連攜作業は不要で、直接ログインするだけで利用できます。**

1. デスクトップ版で Settings > General を開き、Sign Out をクリックして現在のアカウントからログアウトします（モバイル版も同様）。
2. ログイン畫面に戻り、Sign in with Grok をクリックします。
3. Business シートが割り當てられた Grok の認証情報を入力してログインすると、システムが自動的にそのシートの利用枠をマウントします。

### 達成基準

デスクトップ版で Settings > Usage & Billing を開きます。

**プラン管理の下に対応する連攜グレードのバッジが表示され、週間利用枠バーにリセット週期が表示され、アカウントに二重請求が発生していなければ、連攜は成功です。**

## チーム版シートと従量課金（On-demand）の設定

### 概要

チームメンバーは各自の Cursor アカウントで直接 Grok Bot にログインし、利用量はチームの割り當て分から消費されます。**管理者が個別にシートを割り當てる必要はなく、メンバーの承認も不要です**。

週間の利用枠を使い切ると、自動的にオンデマンド利用（請求書には「Billed through Cursor」と表示）に切り替わります。システムには保護メカニズムがあり、**月間上限を超過したタスクでも途中で強制終了されることはなく**、現在のタスクは最後まで完了させることができます。

### 手順

1. クライアントで **設定**（Settings）> **Usage & Billing** を開きます。
2. 「オンデマンド利用の月間上限額」を確認し、Disabled と表示されている場合は右側の **Enable** をクリックして有効化します。
3. 初回設定時はクレジットカードの登録が必要です。[cursor.com/dashboard](https://cursor.com/dashboard) で **支出**（Spending）をクリックします。
4. **Monthly Limit** に毎月の超過利用上限額（使いすぎを防ぐために20ドルや50ドルなどに設定）を入力して保存します。

**iOS および Android のモバイルアプリからは上限額を直接設定できないため**、Web管理コンソールにログインする必要があります。詳細な課金仕様は公式ドキュメント [プランと請求](https://cursor.com/cn/help/grok-bot/plans.md) を參照してください。

### 達成基準

Usage & Billing でオンデマンド利用が有効になっており、設定した上限値が表示されていることを確認します。**週間の利用枠を使い果たしてもタスクがエラーで中斷せず**、オンデマンド枠へスムーズに切り替わって最後まで実行できれば合格です。

## 既存サブスクリプションの切り替え判斷と手順ガイド

![既存サブスクリプションの切り替え判斷と手順ガイド](/info/02-plans-s5.png)

### 概要

統合サブスクリプション「The X Subscription」は2026年10月12日に提供開始されました。自発的に切り替えを行わないユーザーは、既存のプラン、価格、機能がそのまま維持されます。年払いの契約期間は満了日まで完全に有効であり、今後何らかの変更がある場合でも次回更新時にのみ適用されます。

**Web版での切り替え操作は一度確定すると永久に有効となり、サポートに問い合わせても取り消しや舊プランへの復帰はできません**。舊サブスクリプションは決済時に自動終了し日割りで返金されますが、返金額を全額支払う必要がある新プランの代金と相殺することはできず、請求サイクルはその日から新たに起算されます。モバイルクライアントでは現在切り替えに対応していないため、必ずWeb版で行う必要があります。

| 決済チャネルとサブスクリプション製品 | 返金経路と必要なユーザー操作 |
| :--- | :--- |
| Web版で直接購入した舊プラン | 公式により元の決済カードへ日割りで自動返金され、手動の追加操作は不要。 |
| Apple 経由で契約した Grok / X Premium | 公式が申請提出をサポートし、Apple が最終的な返金額を決定。 |
| Apple 経由で契約した Cursor | **ユーザー自身が iOS の「Apple ID → サブスクリプション」で手動解約し、Apple サポートに返金を申請する必要あり**。 |
| Google Play 経由で契約したサービス | **ユーザー自身が Google Play の「お支払いと定期購入」で自動更新を手動解約する必要あり**。 |

### 実踐事例：コミュニティ著者による統合サブスクリプション移行の決斷記録

コミュニティの開発者は2027年まで有効な年払いプランを保有していましたが（※著者自身の記述、未検証）、利用狀況を精査した結果、**手元の舊サブスクリプションを新版の統合サブスクリプションに今すぐ切り替えるのは見送り**、既存プランの自動更新をオフにして様子見を継続することにしました。

舊プランには長期割引が適用されており、強制的に切り替えると元の優待が無効になります。新プランの週間共有プールは自社製モデルのみを対象としており、サードパーティ製モデルの呼び出しはすべて API 定価に応じた別料金となります。また、新プランの週間利用枠プールは各製品で共有されるため、Bot を過度に動かすとWeb版やコード補完の通常利用枠を圧迫してしまいます。

| 対象ユーザー層 | 典型的な特徴と主なニーズ |
| :--- | :--- |
| 切り替えを推奨する層 | 複數の個別サブスクリプションを購入しており月々の出費が30ドルを大幅に超えている、主に公式モデルを利用している、Grok Bot による自動化と X アカウント運用の雙方を密接に連攜させたい。 |
| 切り替えを推奨しない層 | サードパーティ製モデルの追加枠が含まれる舊プランを保有している、あるいは Cursor でのヘビーなコーディングのみが目的で、X のソーシャル機能や動畫生成を必要としない。 |

切り替える前に、まず利用量ダッシュボードを開いて実際の呼び出し內訳を確認し、自社製モデルとサードパーティ製モデルの比率を把握してください。AI ツールは2〜3か月ごとにプラン方針が再編されることが多いため、可能な限り月払いで契約し、長期の年払いで縛られて身動きが取れなくなるリスクを避けるのが賢明です（※著者自身の記述、未検証）。

**Apple 経由で Cursor を定期購読していたユーザーは、移行を決めた場合、モバイル端末の設定から手動で自動更新を解約する必要があります**。Web版でのアップグレードによって自動的に解除されることはありません。

意思決定の分析の詳細は、『[大一統 X サブスクリプション解説：新規ユーザーの選び方、既存サブスクは切り替えるべきか？徹底解説](https://jcng5q8n0f3z.feishu.cn/wiki/Myw6wFW8EicOiRkoEAXcVJqinee)』および『[鐵柱ポストまとめ①：加入、プランと利用枠](https://jcng5q8n0f3z.feishu.cn/wiki/PCZIw5IqgiZLjTkXqNncpxannpc)』をご參照ください。

### 達成基準

舊プランを維持するユーザーは、自動更新の狀態が意図通りであること、および主要モデルの利用枠が維持されていることを確認します。

**新プランへの切り替えを決めたユーザーは、舊サブスクリプションが完全に解除され元の決済チャネルへ返金されていること、新プランが Premium として正常に課金されていること、そして雙方で二重請求やチャネルの競合が発生していないことを確認できれば完了です。**

## 利用量の確認と浪費防止プロンプトの設定

### 概要

**いつの間にか利用枠を使い果たしてしまう事態を防ぐため、まずは各プラットフォーム間の用語の対応関係を把握しておきましょう**。

- 週間使用限度額（デスクトップ）/ 週間利用量（モバイル）：今週の固定プールで、毎週リセットされます。SuperGrok 連攜経由は認証連攜済みであることを示し、獨立した Cursor プランは含まれません。
- オンデマンド利用（Billed through Cursor）：固定プールを使い切った後の追加従量課金です。Web版の月間上限は支出（Spending）下の Monthly Limit で設定します。
- 確認手順：デスクトップ版は設定（Settings）> 利用量と請求（Usage & Billing）、モバイル版は週間利用量をタップ、Web版は [cursor.com/dashboard](https://cursor.com/dashboard) にログインします。

### 手順

**浪費防止の指示を Bot のシステムプロンプトまたは最初の対話に直接書き込みます**。

通常の単一 Bot では1つ目のコードブロックを入力し、低消費の推論に固定してポーリング間隔を広げ、バックグラウンドでのアイドル浪費を防ぎます。

```text
你是一個自動化執行助手。在後續所有任務執行中，必須嚴格遵守以下資源控制規則：
1. 任務規劃階段必須輸出極簡執行步驟，禁止發起非必要的遞歸搜尋與多輪冗餘工具自檢。
2. 在處理程式碼與文本分析任務時，保持適度推理強度，優先給出核心結果，不要輸出冗長無關的修飾性文字。
3. 如果任務涉及定時輪詢或週期監控，單次輪詢時間間隔不得低於 30 分鐘，嚴禁設定分鐘級高頻循環。
4. 嚴禁自行嘗試呼叫外部影片生成或音訊轉換能力；如遇複雜多步驟任務，分步向我彙報進度並等待確認。
```

複數 Bot の協調では2つ目のコードブロックを入力します。**同一タスク內で複數 Bot が頻繁にブロードキャストを行うことは、最も早く利用枠を食いつぶす落とし穴です（※著者自身の記述、未検証）。必ずポイント・ツー・ポイントのチェーン型通信を強制してください**。

```text
你在多智慧體協同流水線中擔任協同節點。必須嚴格執行以下通信約束：
1. 全面採用點對點（Agent-to-Agent）單向派活與回傳，禁止向群聊或未指名的公共上下文廣播全量資料。
2. 傳遞工作流結果時，只提取關鍵欄位與結構化結果摘要，嚴禁將完整的歷史對話記錄重複封裝轉發。
3. 協助任務交付完畢後，立即輸出任務終止狀態，主動退出協作監聽，切斷後續訊息的被動接收與重複解析。
```

### 達成基準

プロンプトを注入した後、**Bot がリソース制約の遵守を明確に返答・確認すること**。自動化スクリプトを3日間連続で実行し、クライアントの Usage & Billing の利用量推移が緩やかで、定期タスクが設定どおりの間隔で実行され、不要な自己診斷ログが出ていなければ合格です。

## よくある落とし穴

### プラン選びとサブスクリプション

- **Bot を使うなら8ドルの Plus プランは買わないこと**。Grok Bot と Cloud agents が含まれていないため、Bot を使いたい場合は必ず30ドルの Premium プランを選択してください。
- **Cursor Pro と SuperGrok の利用枠は合算されません**。両方を同時に契約しても枠が2倍になることはなく、システムはどちらか一方のみをカウントするため、費用の無駄になります。
- サードパーティ製モデルは API 定価に応じて個別課金されます。The X Subscription の週間共有プールは自社製モデルのみをカバーします。
- **年払いではなく月払いを選ぶこと**。ツールやルールは頻繁に変更されるため、年払いを選ぶと今後の柔軟な見直しができなくなります。

### 連攜と解約

- **アカウント連攜は永久に不可逆です**。Cursor に SuperGrok または X Premium+ を連攜すると、サポートであっても解除できません。テスト用のサブアカウントなどで絶対に連攜しないでください。
- 既存サブスクリプションの移行はPCのWeb版からのみ操作可能で、モバイルアプリには切り替え用の入口が用意されていません。
- **iPhone 側で Cursor の自動更新を手動で解約する必要があります**。Web版で統一サブスクリプションに切り替えても App Store の請求は自動で停止しないため、手動で解約しないと雙方から二重請求されてしまいます。

### 利用枠と使用法

- **オンデマンド利用を有効にし、月間上限額を設定すること**。週間の共有プールを使い果たし、かつオンデマンド利用を有効にしていない場合、Bot は即座に応答を停止します。
- **複數 Bot の連攜はポイント・ツー・ポイント通信で行うこと**。グループチャットではメッセージごとに全 Bot へ計算処理がブロードキャストされるため、常駐グループチャットに入れると數往復で週間利用枠を使い果たしてしまいます。

## 完了後の検証手順

1. **アカウント権限**：デスクトップ版を開き、左下のアイコンをクリックしてプランが **Premium、Super、または Ultra** であることを確認します。「新規 Bot」をクリックし、設定パネルが開け、Cloud agents が準備完了と表示されていることを確認します。
2. **マルチデバイスの利用枠**：デスクトップ版の **Settings > Usage & Billing** で週間利用量のパーセンテージをメモし、モバイル版を開いて照合します。両者の數値が完全に一致している必要があります。
3. **支出保護**：ブラウザで [cursor.com/dashboard](https://cursor.com/dashboard) の Spending ページにアクセスし、**Monthly Limit** に上限額（米ドル）が設定されており、クライアント側のオンデマンド枠が Enable 狀態になっていることを確認します。
4. **実際の呼び出し**：プロンプトを送信して Bot に短いタスクを1回実行させ、**ログを確認して餘計な雑談や不要なツール呼び出しがないこと**を確認します。利用量がわずかに動いていれば合格です。
