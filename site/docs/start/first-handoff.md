# 一次好的交接

從一項**需要幾個工具、完成目標明確**的真實任務開始。官方範例：

> 從我們的 CRM 中獲取本週的銷售管道評審列表。跳過已處於活躍跟進序列中的人員。在網頁和 Slack 上調研排名前五的帳戶，找出合適的聯繫人，以我的口吻起草外聯內容，並在明天早上前留下草稿供我審批。

這條訊息說清了：**做什麼、在哪做、要取哪些上下文、完成後長什麼樣、哪裡要我批**。

## 交接樣板

```text
目標：……（完成後的樣子）
來源：……（系統 / 文件 / 網址）
約束：……（不能動什麼）
交付：……（文件格式、路徑）
停下點：……（發送、付款、刪除前先問我）
截止：……
```

## 之後

1. 審查結果並修正。
2. 讓 Bot 記住長期規則（"從現在起，未經批准絕不發送外部訊息"）。
3. 把穩定流程變成技能或例程。
