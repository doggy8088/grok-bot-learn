# X 熱帖案例精選

這裡收錄了 X 平台上引發討論的各類 Grok Bot 實用案例。每個案例均附帶作者的分享原帖，方便查閱具體細節。

**文中所涉及的各項業務收益與成效數位均為作者自述，請讀者結合自身實際需求理性參考。**

### 讓 Bot 撤下你的手機號｜@MinimalDuck

> 原帖：[@MinimalDuck](https://x.com/MinimalDuck/status/2110712459405464057)

為了擺脫推銷騷擾，作者讓 Bot 負責維護個人隱私。Bot 會主動掃描公開的人物搜尋網站與資料經紀商，排查個人手機號的暴露情況。

發現洩露後，Bot 會自動向各平台提交 opt-out 申請並跟進處理確認郵件。**在只提供最少必要資訊的前提下，Bot 會按週期複查並完成撤除流程**。作者已將這套流程做成免費 skill。

這類資料經紀商主要存在於美國，該方案在其他地區的實用性相對有限。

### 讓 Bot 追討快遞延誤費｜@BrianRoemmele

> 原帖：[@BrianRoemmele](https://x.com/BrianRoemmele/status/2111183964329377904)

許多快遞公司的隔夜件都有“保證送達”承諾，一旦超出時限就能申請退費。作者把這類耗費精力的人工交涉交給了 Bot。

Bot 會自動核對帳單找出超時的包裹，隨後前往快遞官網客服渠道逐筆提交索賠。**系統按客戶維度彙總追回的款項，作者稱預計能幫兩家大型企業客戶追回數萬美元**。

原帖提及的類似 Hagglebot 工具目前是否對外開放仍不明確。

### 讓 Bot 自主建站搞副業｜@AlexFinn

> 原帖：[@AlexFinn](https://x.com/AlexFinn/status/2110851435223285909)

作者把 Bot 當作副業主管。Bot 先通過對話訪談使用者的興趣與特長，再借助 X 挖掘受眾的真實要害，構思三個輕量商業點子。

隨後，Bot 會呼叫 Cursor agent 獨立完成建站。**Bot 負責打理 SEO、撰寫 newsletter、排查 bug 與彙報進展，人類只負責外部推廣和分發**。作者已將整套流程做成免費 Bot 樣板。

據作者稱，其運營的站點累計獲得 1100 美元收入，當週進帳達到 1800 美元。

### 三個 Bot 協作管知識庫｜@Argona0x

> 原帖：[@Argona0x](https://x.com/Argona0x/status/2111837226006921640)

作者搭建了一個協同群，由三個帶有獨立記憶的 Bot 共同管理個人數位筆記，避免單線處理複雜資料時的混亂。

分工十分明確：Reader 負責收集原始資料且不改動原件；Librarian 提煉要點並同步修改關聯的十多頁筆記；Checker 在夜間巡檢孤立頁面與陳舊內容。**一旦檢測到觀點衝突，Bot 會主動提醒人工判定而不直接覆蓋，若三十天內沒有新來源則標記為未證實**。

### 首席助理統管一人出海｜@sitinme

> 原帖：[@sitinme](https://x.com/sitinme/status/2109814883688796459)

在單人出海業務場景中，作者設定了層級架構，由首席助理作為核心樞紐對接全部需求。使用者下達寬泛指令後，首席助理會自動拆解任務、新建專職 Bot 深入調研，並在工作日準時輸出彙總簡報。

其餘專職 Bot 各司其職，分別負責整理社媒早報、把英文長推轉化為中文學習文件和講解影片等。**整套體系設定了嚴格的權限隔離，所有對外發文和發信必須經過本人批准**。

Bot 編寫程式碼時會直接呼叫 Cursor，相關改動與 PR 均可在側欄直觀審閱。**開發者只需在手機端配合 Grok Bot 與 Cursor App，即可隨時隨地追蹤任務執行並審查程式碼**。

### 用 Skill 監控對標爆款｜@aehyok

> 原帖：[@aehyok](https://x.com/aehyok/status/2109817788198158347)

為了捕捉同領域的優質選題，作者開源了名為 [x-viral-monitor](https://github.com/aehyok/x-viral-monitor) 的 skill，用來追蹤對標帳號的內容動態。

該方案白天按小時掃描對標帳號近 24 小時內的動態，並在早晨先建立曝光基準線。**一旦單小時內的曝光增量達到預設閾值，系統便會即時推送提醒，並把抓取到的資料沉澱至 GitHub 倉庫**。作者將觸發門檻設為每小時新增 5000 次曝光，使用者可按需調整。

### 每個產品配一個專屬 Bot｜@vikingmute

> 原帖：[@vikingmute](https://x.com/vikingmute/status/2110723552790110229)

作者將日常研發工作遷移至 Grok Bot。他為每個獨立項目單獨組態一個專屬 Bot，讓其熟記程式碼倉庫上下文與測試規範，並通過全域 skill 直接在雲端電腦中呼叫 Cursor CLI 和 Codex CLI。

Bot 會根據任務複雜度選用模型，自行拆解需求、追蹤命令列執行並審查 diff。**在跑完 E2E 和冒煙測試後 Bot 會輸出總結，遇到重要變更還會執行雙模型交叉互審**。此外，Bot 還會定時巡檢 Issue 並推進周計劃。

據作者稱，採用該模式後，每週能穩定上線兩到三個功能。

### 總控帶六組搭建 29 個 Bot 協作體系｜@tanglele0318

### 接入 1Password 授權憑證，交由 Bot 代理網站登錄｜@bot
