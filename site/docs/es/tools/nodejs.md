# Node.js y npm

<ToolMeta id="nodejs" />

Node.js y npm son la base de ejecución para el frontend y diversas CLI de IA, ideales para proporcionar al Bot un **entorno de ejecución para herramientas de línea de comandos modernas**.

## Prompt para enviar al Bot

Copia todo el contenido a continuación y envíalo a tu Grok Bot; este lo instalará y verificará automáticamente en la computadora en la nube, y se detendrá a esperar tu intervención si requiere iniciar sesión o configurar claves.

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝好 Node.js 與 npm（https://github.com/nvm-sh/nvm），以後執行前端項目和各類命令列工具用它。
````

</div>

## Lo que debes hacer tú mismo

- Confirma que la computadora en la nube tenga conexión a la red; no es necesario preparar cuentas externas.
