# Playwright

<ToolMeta id="playwright" />

Playwright es una biblioteca de automatización de código abierto de Microsoft, ideal para permitir que el Bot realice **capturas de pantalla y extracción con renderizado web por lotes**, sin necesidad de consumir manualmente cuotas de interacción del navegador.

## Prompt para enviar al Bot

Copia todo el texto a continuación y envíalo a tu Grok Bot; se instalará y verificará automáticamente en la computadora en la nube, y se pausará para esperar tu intervención si requiere inicio de sesión o configuración de claves.

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 Playwright（https://playwright.dev/python/docs/intro），以後網頁渲染、截圖和抓取任務用它。
````

</div>

## Lo que necesitas hacer tú mismo

- Confirmar que la computadora en la nube cuenta con un entorno de ejecución de Python.
