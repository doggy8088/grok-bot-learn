# DeepSeek Harness

<ToolMeta id="deepseek-harness" />

Agent oficial de código abierto de DeepSeek con arquitectura **«todo es un plugin»**, compatible con escritorio y Web UI. Actualmente se encuentra en fase de vista previa para desarrolladores y es adecuado para **escritura de código**, **investigación y análisis**, **oficina diaria** y **extensión de tareas programadas**.

## Prompt para enviar al Bot

Copia todo el contenido a continuación y envíalo a tu Grok Bot; se instalará y verificará automáticamente en la computadora en la nube, y se detendrá a esperar tus acciones si requiere iniciar sesión o configurar una clave.

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝組態 DeepSeek Harness（https://github.com/deepseek-ai/deepseek-harness），以後日常辦公、調研、寫程式碼和跑定時任務用它。需要組態 DeepSeek API Key 時請停下來提醒我自己填。
````

</div>

## Lo que necesitas hacer tú mismo

- Prepara tu DeepSeek API Key
- Una vez finalizada la instalación por parte del Bot, ingresa tú mismo la API Key en la configuración
