# Feishu CLI (lark-cli)

<ToolMeta id="lark-cli" />

Ferramenta oficial de linha de comando do Feishu, ideal para permitir que o Bot opere documentos em nuvem, planilhas multidimensionais, armazenamento em nuvem e base de conhecimento do Feishu no **computador na nuvem** usando uma identidade pessoal.
O Bot opera documentos em nuvem, planilhas multidimensionais, arquivos em nuvem e base de conhecimento do Feishu no computador na nuvem com uma identidade pessoal.
Adequado para usuários que precisam que o Bot gerencie ativos de documentos, planilhas e arquivos em nuvem do Feishu no computador na nuvem usando uma identidade pessoal.


## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot. Ele irá instalar e verificar tudo automaticamente no computador na nuvem; caso encontre etapas de login ou configuração de chaves, ele fará uma pausa e aguardará a sua ação.

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝組態飛書 CLI（https://github.com/larksuite/cli），以後操作飛書雲文件、多維表格和雲端硬碟用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## O que você precisa fazer

- Preparar uma conta pessoal do Feishu.
- Abrir o link de verificação, inserir o código do dispositivo fornecido pelo terminal e confirmar a autorização.
