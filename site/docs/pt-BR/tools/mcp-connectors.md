# Conectores MCP

<ToolMeta id="mcp-connectors" />

Os conectores MCP abrem o canal de interação entre serviços externos e o modelo, sendo ideais para permitir que o Bot **chame diretamente ferramentas externas e dados na nuvem** para realizar colaborações complexas.

A conclusão é: esta ferramenta serve apenas para permitir que o Bot chame diretamente ferramentas externas e dados na nuvem para realizar colaborações complexas.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot. Ele instalará e verificará tudo automaticamente no computador na nuvem, pausando para aguardar sua ação caso encontre etapas de login ou configuração de chaves.

<div class="tool-prompt">

````text
幫我在你的雲端電腦上接入 MCP 連線器（https://docs.x.ai/grok/connectors），以後呼叫外部工具和同步雲端資料用它。需要第三方授權時把連結發給我，需要填密鑰時請提醒我自己填。
````

</div>

## O que você precisa fazer

- Acessar a página de controle dos conectores no navegador e preparar a conta a ser conectada.
- Preencher o endereço do serviço de destino ou a chave de autorização por conta própria, conforme as instruções.
