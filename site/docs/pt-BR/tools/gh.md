# GitHub CLI (gh)

<ToolMeta id="gh" />

Ferramenta de linha de comando oficial do GitHub, ideal para permitir que o Bot clone repositórios privados, envie código, crie PRs e gerencie Actions no **computador na nuvem**.

A conclusão é: esta ferramenta serve exclusivamente para permitir que o Bot clone repositórios privados do GitHub, envie código, crie PRs e gerencie Actions no computador na nuvem.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot. Ele fará a instalação e verificação automaticamente no computador na nuvem; caso seja necessário fazer login ou configurar chaves, ele fará uma pausa e aguardará sua ação.

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 GitHub CLI（https://github.com/cli/cli/blob/trunk/docs/install_linux.md），以後管理程式碼倉庫、推送分支和提交 PR 用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## O que você precisa fazer

- Ter uma conta no GitHub pronta para uso.
- Abrir o link de autorização no navegador e inserir o código de uso único correspondente.
