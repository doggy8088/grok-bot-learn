# DeepSeek Harness

<ToolMeta id="deepseek-harness" />

Agente oficial de código aberto da DeepSeek com **arquitetura "tudo é plugin"**, com suporte a desktop e Web UI. Atualmente em estágio de prévia para desenvolvedores (developer preview), é ideal para **escrita de código**, **pesquisa e análise**, **tarefas rotineiras de escritório** e **extensão de tarefas agendadas**.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot. Ele instalará e validará automaticamente no computador em nuvem, pausando para aguardar sua ação caso encontre etapas de login ou configuração de chave.

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝組態 DeepSeek Harness（https://github.com/deepseek-ai/deepseek-harness），以後日常辦公、調研、寫程式碼和跑定時任務用它。需要組態 DeepSeek API Key 時請停下來提醒我自己填。
````

</div>

## O que você precisa fazer

- Ter em mãos uma DeepSeek API Key
- Após o término da instalação pelo Bot, insira você mesmo a API Key nas configurações
