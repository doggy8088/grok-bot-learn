# yt-dlp

<ToolMeta id="yt-dlp" />

O yt-dlp é uma ferramenta de linha de comando para download de áudio e vídeo compatível com milhares de sites, ideal para permitir que o Bot **baixe vídeos em lote ou extraia áudio** para posterior processamento de transcrição.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie-o para o seu Grok Bot. Ele fará a instalação e a verificação automática no computador em nuvem; caso encontre etapas de login ou configuração de chaves, ele pausará aguardando sua ação.

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 yt-dlp（https://github.com/yt-dlp/yt-dlp），以後批量下載音影片和提取音訊用它。
````

</div>

## O que você precisa fazer

- Preparar os links das mídias de destino que deseja baixar.
- Exportar o arquivo de cookies correspondente para uso quando encontrar sites que exigem login.
