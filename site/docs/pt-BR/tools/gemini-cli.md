# Gemini CLI

<ToolMeta id="gemini-cli" />

AI Agent de terminal de código aberto do Google, adequado para **usuários pagantes e usuários de projetos do Google Cloud** realizarem interação de terminal e colaboração no desenvolvimento.

A conclusão é: esta ferramenta destina-se apenas a usuários pagantes e usuários de projetos do Google Cloud para interação de terminal e colaboração no desenvolvimento.

## Prompt para enviar ao Bot

Copie todo o conteúdo abaixo e envie para o seu Grok Bot; ele instalará e verificará automaticamente no computador em nuvem, pausando para aguardar sua ação caso encontre etapas de login ou configuração de chaves.

<div class="tool-prompt">

````text
幫我在你的雲端電腦上安裝 Gemini CLI（https://geminicli.com/docs/get-started/installation/），以後終端交互和開發協作用它。需要登錄或授權時停下來把連結發給我由我完成。
````

</div>

## O que você precisa fazer

- Prepare uma conta paga do Google ou uma conta de projeto do Google Cloud.
- Abra o link de autorização enviado pelo Bot no navegador para concluir a autenticação.
